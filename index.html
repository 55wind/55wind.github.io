Public procurement compliance LLM

Reads a public bid notice and decides, for each of 24 legal-violation items, whether the notice breaks the rule, quoting the exact sentence that proves it.

Fixed model (gemma-4-26B-A4B-it), no fine-tuning, no internet, and two hours of inference for the whole test set.

  • vLLM pipeline on one L40S that groups related items into a few prompts per notice and checks that every quote is a verbatim substring of the notice.
  • Per-item decisions that combine the model's judgment with rules from the statute package. On dev, removing a false positive was worth about 4.5 times more F1 than catching a miss, so each item's gate is tuned for precision.
  • Self-labeled a sample of the 20,000 unlabeled notices with frontier LLMs.
  • Paired bootstrap tests on dev to separate real gains from run-to-run noise. The result advanced the team to the final evaluation round.

Python, vLLM, gemma-4-26B-A4B-it

Deepfake detection and takedown requests

A victim registers their face once. The system finds manipulated images of them online, confirms they are deepfakes, and sends the takedown request on their behalf.

  • Face matching with MTCNN and InceptionResnetV1, then a ResNet50 and Xception ensemble to judge manipulation. In the paper the ensemble reached 0.830 top-1 accuracy, against 0.770 for ResNet and 0.790 for Xception alone.
  • Takedown emails go out automatically in the site's language. If no reply comes in time, the case is forwarded to the national cybercrime reporting system (ECRM).
  • Victim identity is stored only as SHA-256 hashes, and collected evidence is encrypted with AES-256-GCM.
  • In 2026 I led the team that turned it into a full dashboard for the ICT Challenge, with FastAPI and Celery workers.

Python, PyTorch, MTCNN, ResNet50, Xception, FastAPI, Celery

AgentTrace

Stops an AI agent's risky action before it runs, and traces a self-replicating prompt injection back to the first infected file and everything it reached.

  • Rules, fingerprints and a provenance graph make every decision, and the LLM only explains it. Everything works with no network and no LLM.
  • A pre-execution gate answers allow, ask or block for each action, adding about 0.08 ms on average in measurement.
  • Tamper-evident log in SQLite with a hash chain, Sysmon event collection, and a read-only MCP server with four tools. Hooks into Claude Code.
  • Ships as a Windows app with a demo mode, so people who do not code can use it.

Python, SQLite, Sysmon, MCP, pywebview

Financial consumer protection agent

Helps a bank customer with a complaint: it finds the law and past dispute rulings that apply, shows how similar cases ended, and drafts the application.

  • Runs on the bank's own machines with a small EXAONE model (1.2B, 4-bit) through Ollama, so complaint text never leaves the bank.
  • Real sources only: 112 dispute-mediation rulings, 217 statute articles and 221 regulator FAQs and interpretations, each with a source URL the schema requires.
  • Answers without a citation are rejected and retried. When retrieval is weak, it says there is no basis and points to the regulator's hotline instead of guessing.
  • Hybrid retrieval (KURE-v1, FAISS and BM25 fused with RRF) plus a knowledge graph. hit@4 of 98.8% on an 81-question golden set, kept as a regression guard. 207 tests.

Python, FastAPI, Ollama, EXAONE, FAISS, BM25, React

LocalPass

Shows foreign tourists Korean blog reviews they can trust. It hides undisclosed ads and AI-written posts, labels sponsored ones, and translates the rest.

  • Each review passes PII masking, a prompt-injection screen, sponsorship-disclosure rules, a Qwen2.5-7B security and context check, and a local Fast-DetectGPT detector before it gets a trust stamp.
  • Reviews reach the model only as tagged data, outputs are forced into a JSON schema, and a review can never be marked trusted when the LLM step fails.
  • Deployed on Vercel, with the 7B model on a Modal GPU that starts on demand and shuts down five minutes after the last request.

Python, FastAPI, Qwen2.5-7B, Fast-DetectGPT, TourAPI, Vercel, Modal

Trust for edge AI

My thesis research: before an edge AI system offloads work to an end node, make sure that node can be trusted.

  • SARO, a two-phase authentication scheme for secure adaptive reverse offloading. First author.
  • Security core for an ETRI edge AI project: authentication, authorization and audit for a KubeEdge cluster designed for 1,000 edge devices. 172 automated tests pass and 15 of 15 attack scenarios are blocked.
  • Auth manager prototype with mTLS between every service, certificate issue, renewal and revocation, an admin approval gate, and a TLS-only message bus that keeps buffering through key rotation.

Python, Kubernetes, KubeEdge, mTLS, RabbitMQ, Docker
